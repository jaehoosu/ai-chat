🧪 예외 상황에서 로딩 화면 종료 테스트

목적: 다양한 오류 상황에서도 로딩 화면이 정상적으로 종료되는지 확인

1. 404 에러 테스트

존재하지 않는 URL로 요청을 보내 404 에러를 발생시킵니다.

2. 타임아웃 테스트

매우 짧은 타임아웃으로 요청 시간 초과를 발생시킵니다.

3. 잘못된 JSON 응답 테스트

JSON이 아닌 응답을 받아 파싱 오류를 발생시킵니다.

4. 네트워크 오류 테스트

잘못된 도메인으로 요청을 보내 네트워크 오류를 발생시킵니다.

5. 정상 요청 테스트 (비교용)

JSONPlaceholder API를 사용한 정상적인 요청입니다.
