✨ 고급 기능들

  • API 기반 메뉴 로딩: REST API에서 동적 메뉴 데이터 로드
  • 로컬 데이터 지원: API 없이도 로컬 데이터로 동작
  • 설정 분리: 메뉴 데이터와 폼 설정을 별도 관리
  • 폴백 시스템: API 실패시 자동 폴백 데이터 사용
  • 상품비교 로직: 대상 선택 시 비교 항목 활성화
  • 동적 폼 생성: 메뉴별 다른 폼 요소 자동 생성
  • 🆕 공통 옵션 관리: streaming, cache, tags 등 API 공통 옵션
  • 🆕 Payload 생성: aimgmt.jsp 스타일의 REST API 페이로드 자동 생성
