[ChatBox] JSON 표시 테스트 - 폐쇄망 버전

이모지 대신 텍스트 기호를 사용하는 안전한 버전입니다.

[테스트] 테스트 케이스

[가이드] JSON 표시 방식 설명

  • 자동 감지: JSON 형태의 문자열을 자동으로 감지
  • 요약 표시: JSON의 구조를 한눈에 파악 가능
    • [배열] 데이터 - 배열 형태의 JSON
    • [객체] 데이터 - 객체 형태의 JSON
    • [JSON] 데이터 - 기타 JSON 데이터
  • 토글 기능: [JSON] 보기/숨기기 버튼으로 원본 JSON을 확인
  • 복사 기능: [복사] 버튼으로 JSON 데이터를 클립보드에 복사
  • 포맷팅: 보기 좋게 들여쓰기와 줄바꿈 적용
  • 안전성: HTML 특수문자는 이스케이프 처리
  • 폐쇄망 지원: 이모지 없이 순수 텍스트만 사용

[정보] 폐쇄망 환경 최적화

  • 이모지 제거: 모든 이모지를 [기호] 형태로 대체
  • 폰트 호환성: 시스템 기본 폰트 사용
  • 외부 의존성 최소화: CDN 대신 로컬 파일 권장
  • 문자 인코딩: UTF-8 인코딩으로 한글 완벽 지원

[변경사항] 이모지 → 텍스트 대체표

기존 (이모지) 변경 (텍스트) 용도
📊 [배열] 배열 데이터 표시
📋 [객체] 객체 데이터 표시
📄 [JSON] 일반 JSON 데이터
🔍 [JSON] 보기 JSON 표시 토글
📋 [복사] 클립보드 복사
