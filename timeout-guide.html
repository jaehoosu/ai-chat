🕐 AJAX 타임아웃 설정 완벽 가이드

1. 기본 타임아웃 시간 (30초)을 설정한 이유

💡 왜 30초(30,000ms)를 기본값으로 설정했나요?

  • 사용자 경험: 30초는 사용자가 기다릴 수 있는 적절한 시간
  • 서버 응답 시간: 일반적인 API 응답 시간 + 네트워크 지연 고려
  • 브라우저 기본값: 브라우저별로 다르지만 보통 2-5분이므로 더 적절한 값 설정
  • 리소스 관리: 무한 대기로 인한 메모리 누수 방지
  • 로딩 화면: 너무 오래 표시되면 사용자가 혼란스러워함

📊 업계 표준 타임아웃 시간

서비스 유형 권장 타임아웃 이유
일반 API 호출 15-30초 대부분의 요청이 처리되는 시간
파일 업로드 60-300초 파일 크기에 따라 가변적
검색/조회 10-15초 빠른 응답이 필요
결제 처리 45-60초 외부 시스템 연동 시간 고려
보고서 생성 120-300초 복잡한 계산이 필요

2. 타임아웃이 없을 경우의 문제점

⚠️ 타임아웃 미설정 시 발생할 수 있는 문제들

  • 무한 대기: 서버가 응답하지 않으면 영원히 기다림
  • 메모리 누수: AJAX 요청 객체가 GC되지 않음
  • 로딩 화면 고착: 로딩 화면이 영원히 표시됨
  • 사용자 혼란: 앱이 멈춘 것처럼 보임
  • 리소스 점유: 네트워크 연결 소켓 낭비
  • 브라우저 성능: 대기 중인 요청이 쌓여서 브라우저 느려짐

3. 브라우저별 기본 타임아웃 동작

🌐 브라우저별 기본 타임아웃 시간

브라우저 기본 타임아웃 특징
Chrome 약 5분 네트워크 상태에 따라 가변적
Firefox 약 90초 about:config에서 설정 가능
Safari 약 60초 iOS에서는 더 짧을 수 있음
Edge 약 5분 Chrome과 유사
IE (구형) 약 1-2분 버전에 따라 차이
⚡ 중요: 브라우저 기본 타임아웃에 의존하면 일관성 없는 사용자 경험을 제공하게 됩니다!

4. 타임아웃 설정 방법과 예제

📝 기본 사용법

// 기본 30초 타임아웃 사용 const result = await $.http.get('/api/data'); // 커스텀 타임아웃 설정 const result = await $.http.post('/api/upload', data, { timeout: 60000 // 60초 }); // 타임아웃 무제한 (권장하지 않음) const result = await $.http.get('/api/data', null, { timeout: 0 });

🎯 용도별 권장 타임아웃

⚙️ 실제 코드 예제

// 1. 검색 API - 빠른 응답 필요 async function searchUsers(query) { try { const results = await $.http.get('/api/search', { q: query }, { timeout: 10000 // 10초 }); return results; } catch (error) { if (error.statusText === 'timeout') { alert('검색 시간이 초과되었습니다. 다시 시도해주세요.'); } } } // 2. 파일 업로드 - 긴 시간 필요 async function uploadFile(fileData) { try { const result = await $.http.post('/api/upload', fileData, { timeout: 120000, // 2분 contentType: false, processData: false }); return result; } catch (error) { if (error.statusText === 'timeout') { alert('파일 업로드 시간이 초과되었습니다. 파일 크기를 확인해주세요.'); } } } // 3. 보고서 생성 - 매우 긴 시간 필요 async function generateReport(params) { try { const report = await $.http.post('/api/reports', params, { timeout: 300000 // 5분 }); return report; } catch (error) { if (error.statusText === 'timeout') { alert('보고서 생성 시간이 초과되었습니다. 관리자에게 문의하세요.'); } } }

5. 타임아웃 에러 처리 모범 사례

async function robustApiCall(url, data) { const maxRetries = 3; let attempt = 0; while (attempt < maxRetries) { try { const result = await $.http.post(url, data, { timeout: 30000 // 30초 }); return result; } catch (error) { attempt++; if (error.statusText === 'timeout') { console.log(`타임아웃 발생 (${attempt}/${maxRetries})`); if (attempt < maxRetries) { // 재시도 전 잠시 대기 await new Promise(resolve => setTimeout(resolve, 2000)); continue; } else { throw new Error('최대 재시도 횟수 초과: 서버 응답 시간 초과'); } } else { // 타임아웃이 아닌 다른 오류는 즉시 throw throw error; } } } }
